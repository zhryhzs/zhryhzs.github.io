## 为什么要有这个博客

因为想找个地方把学过的东西写下来。写下来的过程本身就是一次复习；
写出来的东西，说不定以后能帮到别人。

## 技术栈

这个博客用下面这些搭起来，全部免费：

| 组件 | 作用 |
| --- | --- |
| Hexo | 把 Markdown 变成静态网页 |
| LostStar 主题 | 界面外观，MIT 开源 |
| GitHub Pages | 网页托管，不用服务器 |
| GitHub Actions | 每次提交自动重新构建 |

## 接下来

打算按这个节奏更新：

1. 学习笔记 —— 看了什么、学到什么
2. 踩坑记录 —— 卡了多久、怎么解决的
3. 一些小项目 —— 做了什么，代码放哪

```bash
# 写一篇新文章
hexo new "文章标题"
# 本地预览
hexo server
# 生成静态文件
hexo generate
```

就这样，开始吧 🚀
