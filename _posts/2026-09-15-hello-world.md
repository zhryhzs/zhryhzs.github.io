这是本博客的第一篇文章。

## 为什么要有这个博客

因为想找个地方把学过的东西写下来。写下来的过程，本身就是一次复习；
写出来的东西，说不定以后能帮到别人。

## 这个博客长什么样

- 用 **Jekyll** 生成静态网页
- 用 **Minima** 主题，简洁、够用
- 托管在 **GitHub Pages** 上，免费、不用服务器
- 地址就是 <https://zhryhzs.github.io>

## 接下来

打算按这个节奏更新：

1. 学习笔记 —— 看了什么、学到什么
2. 踩坑记录 —— 卡了多久、怎么解决的
3. 一些小项目 —— 做了什么，代码放哪

```bash
# 以后写文章只要这样
cd zhryhzs.github.io
git add .
git commit -m "新增文章：xxx"
git push
```

推上去等一两分钟，新文章就自动上线了。

就这样，开始吧 🚀
